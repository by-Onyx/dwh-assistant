# Лабораторная 03. RAG в цикле вопросов и ответов

[Выполненный Notebook](notebooks/03_rag.ipynb) · [Результаты проверки](reports/homework_3.md) · [Оглавление проекта](../../README.md)

Ассистент отвечает по трём учебным регламентам сети «Маяк». В диалоге можно спросить, за сколько дней пересчитываются возвраты, уточнить исключение или перейти к сверке выручки. Под ответом видны разделы, которые модель получила для этого вопроса.

## Запуск

Из корня репозитория установите пакет, зависимости из `requirements/notebook.txt` и ядро Jupyter по [корневой инструкции](../../README.md). Для локальных моделей в стандартной папке `var/` выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup_models.ps1 -IncludeRag
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start_notebook.ps1 -Lab 03
```

Если модели уже скачаны в другой каталог, добавьте `-AssetsDir 'D:\папка-с-моделями-и-runtime'` к обеим командам. Установщик проверит имеющиеся файлы и загрузит недостающие. Энкодер занимает около 639 МБ; его SHA-256 закреплён в [манифесте](../../configs/model_manifest.json).

В Notebook выберите ядро **Python (DWH assistant)** и выполните ячейки сверху вниз. Ячейка запуска поднимает два сервера llama.cpp на `127.0.0.1`: энкодер на порту 8083 и генератор на порту 8082. Для запуска на CPU выставьте `CPU = True`. После демонстрации введите свой вопрос в чат. Команда `/exit` освобождает оба порта.

## Как вопрос получает контекст

1. **Документы.** В [базе знаний](knowledge/) три Markdown-файла и шесть тематических разделов. Заголовок `##` задаёт границу раздела. Длинный раздел делится на фрагменты до 900 символов, у каждого сохраняются файл и заголовок.
2. **Индексация.** Qwen3-Embedding-0.6B кодирует название и текст каждого фрагмента. SQLite хранит нормализованный вектор, исходный текст и источник в `var/rag.sqlite3`. При запуске проверяется отпечаток корпуса и идентификатора модели. Изменение документов приводит к атомарной замене индекса. [Энкодер Qwen](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B-GGUF) · [Реализация поиска](../../src/dwh_agent/rag.py).
3. **Поиск.** На каждом обычном ходе тот же энкодер строит вектор вопроса с поисковой инструкцией. Для явных уточнений вроде «А если…» добавляется предыдущий вопрос. Из базы выбираются до двух ближайших фрагментов с косинусной близостью от 0,56.
4. **Генерация.** Qwen3-4B получает [инструкцию](grounded_answer.txt), вопрос, найденные фрагменты и контекст диалога из лабораторной 02. Если сведений недостаточно, инструкция предписывает сообщить об этом. Извлечение личных фактов работает отдельно. Список разделов под ответом формирует приложение по фактической выдаче поиска; оценки видны в событии `rag_retrieved`.

Для своего примера добавьте UTF-8 файл `knowledge/*.md` с заголовком `##` и текстом раздела, затем повторите ячейку индексации. Спросите о правиле другими словами и проверьте подпись источника. Полный перебор векторов подходит для этого небольшого корпуса. Порог близости подобран на учебных вопросах; на другом наборе документов его стоит проверить заново.
