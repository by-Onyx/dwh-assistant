# Витрина продаж учебной сети «Маяк»

## Зерно продаж и ключ позиции
Одна строка fact_sale_line представляет одну товарную позицию проведённого чека. Её бизнес-ключ состоит из store_id, receipt_id и line_no. Количество позиций считают по строкам, а количество чеков — по уникальным парам store_id и receipt_id. Повторное получение позиции обновляет существующую строку по бизнес-ключу.

## Поздние возвраты и горизонт пересчёта
Ночная загрузка перечитывает возвраты за последние 35 календарных дней. Для каждого возврата определяется исходная позиция чека; пересчитывается дневной итог магазина и товара за дату исходной продажи. Для возврата старше 35 дней оператор запускает адресный пересчёт по номеру чека. Простой повтор ночной загрузки такую запись не исправит.
