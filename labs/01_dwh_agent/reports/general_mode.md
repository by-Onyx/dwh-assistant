# Общий ассистент DWH: фактический прогон до 4B

Дата: 09.10.2026. Изменение по просьбе пользователя: помощник для разных предметных областей, а не только витрины учебных продаж. Требование «только до 4B» соблюдено: локально установлены Qwen2.5-1.5B, Qwen2.5-3B и Qwen3-4B-Instruct-2507. Модели больше 4B не скачивались. Новый профиль OpenRouter — liquid/lfm-2.5-2.6b:free; фактически не протестирован из-за HTTP 401. Исторические облачные результаты в REPORT.md относятся к прежнему запуску.

## Что изменилось

- По умолчанию general и local-4b. Старое домашнее задание доступно в режиме practicum.
- Общий промпт выбирает памятку по требованиям, моделированию, остаткам или загрузкам. Учебный catalog используется только по явному запросу.
- При генерации проекта сохраняются пользовательские требования из истории. В финальном независимом проходе исключены ответы модели и ее черновик, чтобы меньше переносить собственные ошибки.
- Добавлены многострочный ввод /paste … /end и --request-file.
- Три ручные функции и разбор обычного текста сохранены. Нет нативных tools, MCP, SQL execution или доступа к реальной схеме БД.
- Новая 4B-модель скачана из закрепленной ревизии; SHA-256 совпал с манифестом. Архив сдачи не содержит моделей и серверных бинарников.

**Это 4/4 проверок завершения и маршрутизации, а не 4/4 правильных проектов.** Ручной просмотр выявил существенные смысловые ошибки:

- Аптека: финал снова объединил продажу позиции и распределение по партиям, использовал даты вместо ID списаний/перемещений, назвал меры измерениями, подменил спрос продажами. Сверка запасов пропустила возвраты и направления перемещений. Истечение срока ошибочно было сделано единственной причиной списания.
- Логистика: смешаны grain рейса и события; загрузка автопарка подменена количеством рейсов на машину; описание связей неполно. Формула своевременности исправлена, но этого недостаточно.
- Университет: появились session_id и attempt_id и доля сдавших среди зарегистрированных, но посещаемость всё еще использует неверный знаменатель; доля не сдавших смешана с отсутствием попыток. Меры названы измерениями.
- В вопросах модель смешивает дефицит доступности с истечением срока даже после явного ограничения.

Предыдущая самопроверка по длинной памятке копировала черновик практически целиком. Замена на независимую генерацию частично исправляет детали, но не доказала семантическую надежность. Нельзя объявлять модель полноценным автономным архитектором. Общий режим пригоден для диалога и получения черновика; проект требует проверки человеком. В pharmacy_reviewed.md есть отдельно помеченная ручная корректировка и неизмененный сырой ответ для сравнения.
